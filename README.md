## 4. Setup

Requires Python 3.10 or newer and Git. From a terminal:

```bash
git clone https://github.com/SamMcRae05/MMA3001-Project---34977600.git
cd MMA3001-Project---34977600

python -m venv .venv            # create an isolated Python environment
.venv\Scripts\activate          # Windows (macOS/Linux: source .venv/bin/activate)
pip install -e ".[dev]"         # install this project and its dependencies
```

Then obtain the dataset as described in [`data/README.md`](data/README.md).

## 5. Usage

1. Complete the setup above, including placing the raw data files in `data/raw/`.
2. Open the notebooks in VS Code (or Jupyter) and select the `.venv` kernel.
3. Run each notebook from the top (**Restart**, then **Run All**). The numbers give the order the work was
   done in, and each notebook loads the raw data itself, so each can also be run on its own:
   - `01_data_audit.ipynb` – explores the raw data.
   - `02_cleaning.ipynb` – applies and checks the cleaning step.
   - `03_gap_filling.ipynb` – the main experiment. It takes a few minutes, mostly loading the data and
     running the experiments.

The functions the notebooks use are in `src/mma3001/` (`io.py` loads the data, `cleaning.py` removes repeated
uploads, `gapfill.py` makes and fills the gaps and scores the methods).

**Settings and the final test (notebook 03):** every setting is in the *Settings* cell (section 1) and is
explained in the decisions log in `report/report.md`. The settings were chosen using development data only.
The final test on the held-back data (section 9) runs only when `RUN_TEST = True`. It was run once, after the
settings were fixed. Rerunning it with the same settings and seed gives the same results. If any setting is
changed, the test data is no longer an independent test.
